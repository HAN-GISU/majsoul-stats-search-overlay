 작혼 전적 검색 오버레이 v1.1.2  © 2026 HAN-GISU
════════════════════════════════════════════════════

게임 화면 위에 나와 상대의 전적을 띄워주는 오버레이입니다.
전적 데이터는 아마에코로모(雀魂牌谱屋)에서 가져옵니다.
  https://amae-koromo.sapk.ch/

필요 환경: Windows 10/11, 인터넷 연결
(기본 기능은 별도 설치 없이 동작)

※ 전적 데이터 특성상 4인 금의 방(금탁) 이상 단위전 기록이
   있는 계정만 조회됩니다 - 본인·상대 모두.
   은/동의 방에서만 친 계정은 표시되지 않습니다.


■ 설치 (3단계)
────────────────────────────────────
1. 이 폴더를 원하는 위치에 통째로 압축 해제
   (릴리스에는 두 종류가 있습니다 - "엔진 포함판(full)"은
    인식 엔진이 들어 있어 이대로 끝, "경량판"은 아래
    인식 엔진 설치 안내를 참고)
2. '작혼 오버레이.exe' 더블클릭 → 화면 왼쪽 위에 전적 박스가 뜸
3. 박스에 나타나는 "작혼 닉네임 입력" 칸에 본인 닉네임을 넣고 확인
   (이후 변경은 설정(톱니 버튼) 맨 아래 "내 닉네임"에서)

※ 처음 실행 시 "Windows의 PC 보호" 창이 뜨면
   [추가 정보] → [실행] 을 누르면 됩니다.
   실행이 막히면 tools 폴더의 overlay-start.bat 으로도 켤 수 있습니다.
※ 바탕화면 바로가기는 '작혼 오버레이.exe' 우클릭 →
   [바로가기 만들기]로 만들면 아이콘까지 그대로 적용됩니다.


■ 사용법
────────────────────────────────────
박스에 마우스를 올리면 버튼이 나타납니다:
  돋보기 (왼쪽 위) : 상대 스캔 — 대국 중 누르면 상대 3명의 전적
                     박스가 각자 명패 옆에 표시됨
  물음표           : 도움말
  새로고침         : 즉시 갱신
  리포트           : 리포트 카드 (일간~연간·지정 기간 통계,
                     그래프, PNG 저장)
  톱니(설정)       : 표시 항목, 통계 기준, 키, 테마 등 전부
  반달(테마)       : 테마 전환 (밝은 / 다크 / 투명)

기본 단축키 (설정에서 변경 가능):
  F8  : 상대 스캔        F7 : 상대 박스 모두 닫기
  F10 : 오버레이 종료
  드래그: 위치 이동

기타 기능:
  - 기보 링크를 복사하면 모탈(Mortal) AI 리뷰 페이지가 자동으로
    열립니다 (실행 버튼만 누르면 분석 시작)
  - 오늘 순위와 수지, 그래프는 1분마다 자동 갱신
    ※ 전적은 아마에코로모(雀魂牌谱屋) API에서 가져오며, 대국 종료 후
      사이트 반영까지 보통 5~15분(길면 수십 분) 걸릴 수 있습니다.
      사이트에 반영되는 즉시 오버레이에도 나타납니다.
      https://amae-koromo.sapk.ch/


■ 상대 스캔이 잘 되려면: 인식 엔진 설치 (권장)
────────────────────────────────────
※ 엔진 포함판(full) ZIP을 받았다면 이미 들어 있으므로
   이 섹션은 건너뛰세요. 경량판 사용자만 해당됩니다.

인식 엔진을 설치하면 상대 스캔이 훨씬 빠르고 정확해집니다.

  1. 아래 주소에서 PaddleOCR-json_v1.4.1_windows_x64.7z
     (약 88MB)를 받습니다:
     https://github.com/hiroi-sora/PaddleOCR-json/releases/tag/v1.4.1
  2. 압축을 풀어 나온 폴더를 오버레이 폴더 안의 engine 폴더에
     넣습니다. (engine 폴더가 없으면 새로 만드세요.
     하위 폴더 이름은 무엇이든 자동 감지됩니다.)
  3. 끝 - 다음 스캔부터 자동으로 사용됩니다.

  ※ 7z 해제는 반디집이나 7-Zip이 필요합니다.
     (Windows 11 23H2 이상은 탐색기에서 바로 풀림)

[엔진 없이 쓰기 - 대안]
엔진이 없으면 Windows 내장 문자인식으로 동작합니다.
이 경우 외국어 닉네임 인식을 위해 언어팩을 설치하세요:
  1. tools 폴더의 "install-ocr.bat" 더블클릭
  2. 관리자 권한 창(UAC)에서 [예]
  3. 파란 설치 창이 알아서 진행 - 창 안을 클릭하지 마세요!
     (클릭하면 일시정지됨. 멈춘 것 같으면 Esc 한 번)
  4. "설치 완료"가 뜨면 오버레이를 껐다 켜기 (F10 → 재실행)
이 설치는 Windows 공식 언어 구성요소만 추가하며, 시스템 표시
언어나 키보드 설정은 전혀 바뀌지 않습니다.


■ 스팀에서 게임과 같이 켜고 끄기 (선택)
────────────────────────────────────
스팀 라이브러리 → 작혼 우클릭 → 속성 → 시작 옵션에 아래 한 줄
(경로는 본인이 압축 푼 폴더로 수정):

"C:\경로\majsoul-overlay\tools\steam-wrapper.exe" %command%

→ 게임 켜면 오버레이 자동 시작, 게임 끄면 자동 종료
→ steam-wrapper.exe가 없으면 오버레이를 한 번 실행하면
   자동 생성됩니다


이 프로젝트의 코드는 AI 도구(Anthropic Claude)를 활용해
작성되었습니다.

인식 엔진(선택, 엔진 포함판에 동봉)은 PaddleOCR-json
(hiroi-sora, Apache-2.0 - 전문은 THIRD-PARTY-NOTICES.txt 참조)을
사용합니다.
  https://github.com/hiroi-sora/PaddleOCR-json

안정단위 계산식과 상수는 amae-koromo(雀魂牌谱屋)의 구현을
기반으로 일부 수정한 것입니다(모드별 상수, 금탁·동장 확장).
안정단위는 기준 구간에서 가장 많이 친 모드의 통계만으로
계산하며, 라벨에 그 모드를 병기합니다 (예: 금남·1개월 기준). 원저작권(c) 2020 SAPikachu, MIT License 고지는
THIRD-PARTY-NOTICES.txt에 포함되어 있습니다.
