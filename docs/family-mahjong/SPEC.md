# 가족 리치마작 입문 키트 — 스펙 (초안 v0.1)

> 상태: 초안 · 작성일 2026-10-06 · 이 오버레이와는 별개 프로젝트 (호스팅 위치는 [열린 질문](#10-열린-질문) 참고)

## 1. 배경과 목표

### 문제

리치마작 자체는 생각보다 어렵지 않습니다. 진입장벽은 **처음부터 알 필요 없는 규칙을 첫날 한꺼번에 가르치는 데서** 생깁니다.

| 장벽 | 체감 난이도 | 첫날 필요? | 이 키트의 대응 |
|---|---|---|---|
| 패 읽기 (萬·東·發 같은 한자) | 중 | 필요 | 색 + 숫자 표기, 한글 병기 |
| 완성형 (몸통 4 + 머리 1) | 하 | 필요 | 루미큐브에 빗대어 설명 |
| 역이 없으면 화료 불가 | **상** — 초보가 가장 많이 좌절하는 지점 | 나중 | Lv1–2는 역 없이 화료, Lv3에서 역 4개만 |
| 점수 계산 (판·부) | **최상** | 불필요 | 부 계산은 가족 룰에서 **영구 생략** — 간이 점수표 |
| 산 쌓기·왕패·도라 | 중 | 불필요 | Lv3까지 산 쌓기 생략 |
| 후리텐·깡·치 타이밍 | 중 | 나중 | 레벨마다 하나씩 추가 |
| 공격/수비 판단 | 상 | 불필요 | 규칙 하나("현물만 버린다")만 |
| '마작 = 도박' 이미지 | 부모님 세대에선 **상** | — | 돈 걸지 않음, 칩·스티커, 건강마작 프레이밍 |

### 목표

3세대 가족(부모님 50~60대 이상, 형제·배우자, 초등~중등 아이)이 **약 8주 안에 동장전 한 판을 코치 도움 없이 완주**한다. 점수 계산은 도구에 맡겨도 된다.

### 성공 지표

| 시점 | 지표 |
|---|---|
| 첫 세션 | 15분 안에 전원 첫 화료 (Lv1) |
| 3주 차 | 각자 "나 텐파이야, ○○ 기다려"를 스스로 말할 수 있음 |
| 4~5주 차 | 리치를 걸고 역이 있는 화료 성공 |
| 8주 차 | 실물 또는 작혼 친구전에서 동장전 완주 |
| **진짜 지표** | 가족이 **먼저** "마작 하자"고 말한다 |

### 비목표

- 사람이 판·부 계산을 하게 만드는 것
- 실력 향상 이론 (패효율 심화, 읽기, 수비 이론)
- 돈을 거는 것
- 작혼 랭크전 실시간 보조. 이 오버레이에 훈수 기능을 넣지 않는다 (악용 소지가 있고 이용약관상 문제가 될 수 있음)

## 2. 대상 사용자

| 페르소나 | 특징 | 설계 시사점 |
|---|---|---|
| **부모님** (50~60대 이상) | 한자는 읽음. 화투 경험 가능. '도박' 인식. 작은 글씨와 빠른 UI가 힘듦 | 실물 패 우선, 큰 글씨 인쇄물, 앱은 큰 글씨 모드. 영업 문구가 가장 중요 |
| **형제·배우자** (20~40대) | 앱에 익숙, 경쟁심 있음, 시간이 부족 | 작혼 친구전으로 빨리 넘김. 진도가 빠르면 **2차 코치**로 승격 |
| **아이** (초등~중등) | 한자를 못 읽음. 집중 15~20분. 계속 지면 금방 흥미를 잃음 | 색 + 숫자 패, 짧은 판, 스티커 보상, 페어전, 핸디캡 룰 |
| **코치** (본인) | 유일한 숙련자. 여러 명을 동시에 봐야 함 | **코치 부담 줄이기가 설계 목표**: 손패 공개, 셀프 체크 앱, 2차 코치 육성 |

## 3. 설계 원칙

1. **15분 안에 첫 화료.** 규칙 설명보다 "다 맞췄다!"는 경험이 먼저다.
2. **한 번에 규칙 하나.** 레벨업처럼 추가하고, 잠긴 규칙은 보여주지도 않는다.
3. **계산은 기계가, 사람은 모양만.** 부 계산은 가족 룰에서 영구 생략한다.
4. **코치는 한 명, 질문은 셋.** 손패 공개, 페어전, 앱 셀프 체크로 코치에게 몰리는 질문을 줄인다.
5. **레벨이 달라도 같은 테이블.** 개인별 핸디캡 룰로 진도 차이를 흡수한다.
6. **앱 때문에 시작을 미루지 않는다.** 인쇄물만으로 Lv1–2가 돌아가야 한다. 앱은 막히는 지점만 메운다.

## 4. 커리큘럼 (A) — 레벨 구조

주 1회 이상 모이는 것을 기준으로, 한 세션은 30~60분(아이 참여 시 20분 단위로 끊음)입니다.

| 레벨 | 새로 배우는 것 | 핵심 하우스룰 | 졸업 조건 | 예상 |
|---|---|---|---|---|
| **Lv0** 패 소개 | 만수·통수·삭수 1~9, 자패 7종 | 꽃패 제거 | 패 분류 게임 1분 안에 완료 | 1주 차 (10분) |
| **Lv1** 모양 맞추기 | 몸통(슌쯔·커쯔) 4 + 머리 1, 쯔모 | 손패 공개, 산 없이 섞어둔 패에서 뽑기, 쯔모만 가능, 역·점수 없음 | 혼자 힘으로 화료 1회 | 1주 차 |
| **Lv2** 남이 버린 패로도 | 론, 텐파이, 대기패 | 손패 비공개로 전환. 아직 역 없이 화료 가능, 울기 없음 | 텐파이와 대기패를 스스로 말하기 | 2~3주 차 |
| **Lv3** 역이 하나는 필요 | 리치, 멘젠쯔모, 탕야오, 역패 | **울지 않았으면 리치하면 된다.** 리치에 칩 1개 걸기. 산 쌓기 시작 | 리치 걸고 화료 1회 | 3~4주 차 |
| **Lv4** 울기와 보너스 | 퐁·치, 도라·적도라, 점수봉 | 쿠이탕 허용. "울면 리치를 못 거니, 역패나 탕야오가 있을 때만 운다." 간이 점수표 사용 | 울어서 역 있는 화료 1회 | 5~6주 차 |
| **Lv5** 실전 규칙 | 후리텐, 유국·텐파이료, 친 연장, 동장전 흐름, 수비 한 줄 | 리치가 들어오면 **그 사람이 버린 패(현물)만 버린다** | 동장전 1판 완주 | 7~8주 차 |
| **졸업 후** | 역 카드 추가 (치또이쯔 → 또이또이 → 혼일색 → 일기통관 → 삼색동순 …), 반장전, 작혼 친구전 데뷔 | | | |

### 4.1 레벨별 상세

**Lv0 — 패 소개 (10분)**
- 136장 = 34종 × 4장. 수패 3종(만·통·삭) × 1~9, 자패 = 바람 4(동남서북) + 삼원 3(백발중)
- 활동: 섞인 패를 종류별로 빨리 분류하기 (가족 대항)
- 비유: "루미큐브처럼 색깔별 숫자 패가 있고, 그림 패가 조금 더 있다"

**Lv1 — 모양 맞추기**
- 진행: 13장을 받고, 내 차례에 1장 뽑고 1장 버림. 몸통 4 + 머리 1을 먼저 완성한 사람이 "쯔모!"
- 몸통 = 같은 종류 연속 3장(슌쯔, 예: 3·4·5만) 또는 같은 패 3장(커쯔). 머리 = 같은 패 2장
- 자패는 연속이 안 됨 → 같은 것 3장만
- **산 쌓기를 생략한다.** 패를 엎어서 섞어두고 아무 데서나 집는다. 처음 하는 사람에게 셋업은 그 자체로 장벽이다
- 손패를 펴고 하며, 코치가 돌아다니며 힌트를 준다
- 이기면 칩(또는 스티커) 1개
- 마무리 대사: "다음엔 **남이 버린 패**로도 이길 수 있어" (다음 세션 예고)

**Lv2 — 론과 대기패**
- 론: 남이 버린 패로 완성. 텐파이: 한 장만 오면 완성되는 상태
- 손패를 숨기기 시작. 대신 앱의 손패 체커로 셀프 체크 (§5 B-3)
- 버림패는 자기 앞에 순서대로 놓는 습관 (Lv5 후리텐 대비)
- 아직 역 없이 화료 가능, 울기 없음

**Lv3 — 역이 하나는 필요** (리치마작의 핵심 관문)
- 처음 가르치는 역은 4개만:
  - **리치**: 울지 않고 텐파이 → 선언하고 칩 1개 걸기. 이후 손패를 바꿀 수 없다
  - **멘젠쯔모**: 울지 않고 쯔모로 화료
  - **탕야오**: 2~8 수패로만 완성
  - **역패**: 백·발·중, 또는 자기 바람·판 바람을 3장
- 역 카드 한 장에 정리: **"울지 않았으면 리치하면 된다"**
- 산 쌓기 시작 (왕패와 도라는 아직 없음)

**Lv4 — 울기와 보너스**
- 퐁 → 치 순서로 추가. 깡은 "같은 패 4장이면 깡 하고 1장 더 뽑는다" 정도만
- 울면 리치를 못 거는 트레이드오프를 이 시점에서 자연스럽게 배운다
- 도라 표시패, 적도라. 판수가 생기므로 점수봉 도입 (25,000점 시작)
- 점수는 **간이 점수표** (§6)로 계산. 정확한 점수가 궁금할 때만 앱 사용

**Lv5 — 실전 규칙**
- 후리텐: 내가 버린 패로는 론을 못 함 (작혼은 자동 판정)
- 유국, 텐파이료, 친 연장, 동장전 흐름
- 수비는 한 줄만: 리치가 들어오면 현물만 버린다 (현물이 없으면 그때만 고민)

### 4.2 세대가 섞인 테이블 운영

- **개인별 레벨 룰 (핸디캡).** 같은 테이블이라도 각자 자기 레벨 규칙을 적용한다. 예: 어른이 Lv4여도 Lv2인 아이는 역 없이 화료 가능, 후리텐 면제. 실물 플레이에서만 가능 (작혼은 전원 동일 규칙)
- **페어전.** 초보와 숙련자가 2인 1조로 한 자리를 맡고 상의해서 친다. 아이 + 부모, 부모님 + 형제
- **짧은 판 포맷.** 아이가 있으면 동풍전 대신 "4국만" 또는 "먼저 3번 화료하면 승리"
- **2차 코치 육성.** 진도가 빠른 형제·배우자가 Lv4에 도달하면 페어전 파트너 역할을 맡긴다
- **4명이 안 될 때.** 실물이면 3명 + 페어, 작혼이면 친구전에서 빈자리 채우기 (AI 추가 기능 확인 필요)

### 4.3 실물과 작혼의 역할 분담

| | 실물 (식탁) | 작혼 친구전 |
|---|---|---|
| 강점 | 분위기, 손패 공개 코칭, 개인별 핸디캡 룰 | 규칙·후리텐·점수 자동, 모임 사이 연습 |
| 투입 시점 | Lv0~ 전체 | **Lv3 이후** (작혼은 역 없는 화료를 허용하지 않기 때문) |
| 추천 설정 | — | 동풍전, 쿠이탕 ON, 적도라 ON |

## 5. 웹 학습 도우미 (B) — 기능 스펙

커리큘럼에서 **막히는 지점만** 메우는 모바일 우선 웹앱입니다. 로그인 없음, 한국어 UI, 오프라인 동작.

### 5.1 기능 우선순위

| ID | 기능 | 메우는 지점 | 레벨 | 우선순위 |
|---|---|---|---|---|
| B-1 | **패 도감**: 34종, 표기 모드 토글 | 패 읽기 | Lv0~ | P0 |
| B-2 | **레벨 룰북**: 가족의 현재 레벨까지만 표시, 코치가 다음 레벨 해제 | 규칙 기억 | 전체 | P0 |
| B-3 | **손패 체커**: 손패 입력 → 완성 / 텐파이(대기패와 남은 장수) / "완성까지 N장" / (Lv3+) "역 없음 — 리치하세요" 경고 | 코치 대신 셀프 체크 | Lv2~ | P0 |
| B-4 | **간이 점수표**: 판 → 점수, 친 1.5배 | 점수 | Lv4~ | P0 |
| B-5 | **혼자 모양 맞추기**: 1인 쯔모·타패, 18순 안에 완성. 힌트 = "완성까지 N장" | 모양 감각 | Lv1~ | P1 |
| B-6 | **대기패 퀴즈**: 텐파이 손패를 보고 기다리는 패 고르기 (쉬움 → 어려움) | 대기패 파악 | Lv2~ | P1 |
| B-7 | **역 퀴즈**: 화료형을 보고 역이 있나, 무슨 역인가 | 역 | Lv3~ | P1 |
| B-8 | **정밀 점수 계산기**: 판·부 포함 정확한 점수 | "정확히 몇 점?" | Lv4~ | P2 |
| B-9 | **뭘 버릴까**: 향청수와 유효패 수 기준 정답 | 패효율 기초 | 졸업 후 | P2 |
| B-10 | **가족 진도판**: 누가 어느 레벨인지, 스티커와 뱃지 | 동기부여 | 전체 | P2 |

### 5.2 패 표기 (B-1, 앱 전체 공통)

| 모드 | 예: 一萬 / 中 | 대상 |
|---|---|---|
| **색 + 숫자** (기본) | 빨간 **1** / "중" | 아이, 첫 주. 만=빨강, 통=파랑, 삭=초록 (루미큐브 감각) |
| **한글 병기** | 一萬 + "1만" / 中 + "중" | 부모님, 과도기 |
| **실제 패** | 一萬 / 中 | 작혼과 실물 패에 적응 |

- 색약을 고려해 색만으로 구분하지 않고, 종류 아이콘이나 글자를 함께 표시
- 레벨이 오르면 실제 패 모드를 권장해서 실물·작혼으로 자연스럽게 넘어가게 한다
- 패 이미지는 **자체 SVG로 생성** (라이선스 이슈 회피). 통수 원과 삭수 막대는 코드로 그린다

### 5.3 손패 입력 UX (B-3, B-8)

- **패 키보드**: 만·통·삭·자 4줄 × 최대 9칸, 큰 버튼. 같은 패는 4장까지만, 입력하면 자동 정렬
- 큰 글씨 모드 (부모님): 버튼과 글자를 키우고 한 줄씩 넘겨 보기
- 고급 입력: `123m456p789s11z` 표기 붙여넣기
- 카메라로 패 인식은 범위 밖 (§8)

### 5.4 화면 구성

1. **홈**: 구성원 선택 (기기 로컬), 현재 레벨, 오늘의 연습 1개
2. **패 도감** (B-1)
3. **룰북** (B-2): 레벨 카드, 잠긴 레벨은 숨김
4. **체커** (B-3): 식탁에서 가장 많이 쓸 화면이라 홈에서 한 번 탭으로 진입
5. **연습** (B-5~7)
6. **점수** (B-4, B-8)

### 5.5 기술 방향

- 정적 웹앱 (HTML/CSS/JS). 빌드 도구는 필요할 때만. PWA로 홈 화면 추가와 오프라인 지원
- 핵심 로직은 직접 구현:
  - `tiles` — 34종 정의, 표기 모드
  - `hand` — 손패 분해, 향청수, 대기패, 남은 장수
  - `yaku` — Lv3 역 4개 (+ 치또이쯔 해제 시)
  - `quiz` — 퀴즈 문제 생성기 (정답은 `hand`·`yaku`로 검증)
- P0~P1은 외부 라이브러리 없이 가능. P2 정밀 점수(B-8)만 오픈소스 판정 라이브러리 도입 검토 (Python `mahjong`, JS `riichi` 등 — **라이선스 확인 필요**)
- 상태는 `localStorage` (구성원, 레벨, 뱃지). 기기 간 공유가 필요한 진도판(B-10)은 방식 미정
- 테스트: 향청수·대기패 계산은 알려진 손패 케이스로 단위 테스트 (다면 대기, 치또이쯔, 4장 사용 대기 등)

## 10. 열린 질문

1. **실물 패**: 집에 있는가? 새로 산다면 귀퉁이에 숫자가 적힌 패(인덱스 패)를 사거나, 기존 패에 라벨 스티커를 붙일지
2. **웹앱 위치**: 이 저장소의 하위 폴더 / 별도 저장소 + GitHub Pages / claude.ai 아티팩트 중 어디에 둘지
3. **작혼 친구전**: 하우스룰 설정 범위(쿠이탕, 적도라, 동풍전)와 빈자리 AI 추가 가능 여부 확인
4. **보상 체계**: 칩, 스티커, 실제 보상(간식 선택권 등) 중 무엇을 쓸지. 아이 기준으로 정하기
5. **B-8 라이브러리**: 직접 구현과 오픈소스 도입 중 무엇으로 할지, 라이선스 확인
6. **진도판 공유**: 각자 폰에서 같은 진도판을 볼 필요가 있는지, 아니면 냉장고에 붙인 스티커판이면 충분한지
